# qi202.github.io

Qi 的个人 GitHub Pages 网站，基于 Hugo Blox Academic CV 模板制作。

## 当前页面

- 中英双语个人简介
- 项目展示入口
- GitHub 联系方式
- 响应式深浅色界面

个人照片、真实姓名、邮箱和项目内容可继续在 `content/` 与
`data/authors/me.yaml` 中替换。

## 本地预览

安装 Hugo Extended 后运行：

```bash
hugo server
```

## 发布

推送到 `qi202/qi202.github.io` 后，GitHub Actions 会自动构建并发布网站。
